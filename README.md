# Ismoiljon Polatov — Shaxsiy Portfolio Veb-sayt

Bu veb-sayt **Ismoiljon Polatov** ning shaxsiy portfolio veb-sayti bo'lib, Frontend dasturchi sifatidagi ko'nikmalari, yutuqlari va loyihalarini namoyish etadi.

## 🚀 Texnologiyalar
- **HTML5** — Semantik va toza tuzilma
- **CSS3** — 2 xil rangdan iborat zamonaviy minimalist (Monochrome Dark) dizayn, Flexbox, CSS Grid, `@media` responsivlik
- **JavaScript (ES6+)** — Interaktiv mobil menyu, real-time soat vidjeti, matnlardan bir bosishda nusxa olish (Clipboard)
- **Git & GitHub** — Kod nazorati va versiyalar boshqaruvi
- **Vercel** — Jonli efirga (deploy) chiqarish
